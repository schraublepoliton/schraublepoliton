Summary

Performance issues manifest as long load times, frame drops and memory growth over extended sessions. The following recommendations are prioritized for short and medium term.

Short-term fixes

  • Precompile frequently used shaders during an offline build step.
  • Introduce per-map asset streaming limits and prioritize player-facing assets.
  • Add memory-use dashboard and leak detectors to the release build channel.

Medium-term improvements

  • Redesign loading pipeline to parallelize IO and scene preparation.
  • Implement progressive LOD and occlusion culling to reduce GPU load on dense maps.
  • Stagger and batch expensive background tasks (hideout/AI updates) to avoid spikes.

Monitoring & telemetry

Ship instrumentation for frame time, memory, and GPU telemetry; correlate with player reports to identify problematic builds and maps.
